Playground

A real request against the talk’s own API. Pick a verb, type an endpoint, edit the body — then send it and read what comes back. Nothing fires on load and nothing is remembered: every call is a click.

Request

GET

Accept: application/json
Content-Type: application/json

Tab indents, Shift+Tab outdents, Esc leaves the box. On GET the body is ignored — a GET asks for data, it sends none.

Press Send. Whatever the endpoint on the left answers lands here — status, headers and payload.

The API sleeps when nobody is calling it, so the first request of the day can take up to a minute. Every one after that is immediate.
